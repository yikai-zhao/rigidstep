This viewer replays a saved simulation trace; it does not run the physics solver in JavaScript. The C++ engine exports every state and diagnostic. Face-face contacts are clipped to at most four points; edge-edge contacts and the position correction remain simplified; this is a performance/correctness research prototype, not a production-grade game physics engine.
